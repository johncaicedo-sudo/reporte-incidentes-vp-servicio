INFORME MAESTRO DE PROYECTO: PORTAL DE INTERMEDIARIOS

Proyecto Jira: GD-907 | Portal de Intermediarios (antes “Unificación de Plataformas”)

1. Resumen Ejecutivo

  • Objetivo: Centralizar, modernizar y entregar funcionalidades de autogestión, comerciales y de talento humano para intermediarios de Seguros Bolívar.
  • Estabilidad: Efectividad superior al 99.9% en producción.
  • Crisis actual: Fase III con bloqueos externos de integración (backend Saghi).
  • Arquitectura: Angular MicroFrontends + Java 11/Spring Boot + Lambdas Python 3.9 sobre AWS (ECS, Lambda, RDS).
  • Equipo: 6 desarrolladores + Líder Técnico + PO + Jefe de proyecto.
  • Ventana crítica: Entregable 6 (Gestión Humana) entre 4 Mayo – 31 Agosto 2026.

4. Contenido Estratégico

  • Diagnóstico Crítico: Fase III bloqueada por dependencia externa de Saghi para backends de Gestión Humana.
  • Transición Arquitectónica: Legacy (Oracle + FileNet) → Moderno (PostgreSQL + AWS + MicroFrontends).
  • Modelo de Entrega: Entregables incrementales con validación en QA antes de producción.
  • Excelencia Operativa: 31 ítems activos en 3 ecosistemas para mantener estabilidad >99.9%.

DEPENDENCIAS, RIESGOS Y TEMAS CRÍTICOS

Cruce: Arquitectura Confluence × Cronograma × Integraciones externas

Dependencias Críticas (Bloqueos Externos)

ALTO Backend Saghi

Dependencia alta que hace parte de la ruta crítica para los Entregables 4, 5 y 6. Sin backend de Gestión Humana, no se puede desarrollar Calendarios, Certificados, Perfil ni Pagos/Comisiones. Fecha límite: Junio 2026.

Fecha límite: Junio 2026
CRÍTICO FileNet / Oracle Legacy

Sistemas legacy con latencia elevada y errores 500 forzados. Tronador (Oracle) es el core de pólizas. FileNet maneja gestión documental legacy. Ambos generan inestabilidad en integraciones.

Mitigación: Circuit breakers + Datadog APM
PENDIENTE Microfront Precobros

Certificación visual pendiente del microfrontend de Precobros. Bloquea la integración visual completa del portal. Requiere validación de UX y QA visual.

Responsable: Equipo Frontend + QA

Dependencias Técnicas

⚙ Integración Saghi (Gestión Humana)

Backend principal para Entregable 6. Provee APIs de Calendarios, Certificados, Perfil y Pagos/Comisiones. Dependencia externa crítica con fecha límite en Junio 2026.

🔗 Carpeta Única + Gestor Documental + Gestor de Flujos

3 integraciones nuevas en paralelo. Carpeta Única unifica documentos, Gestor Documental reemplaza FileNet, Gestor de Flujos orquesta procesos.

🔒 FCA (Facturación y Cartera)

Integración requerida para Entregable 7 (Gestión de Cartera). Sistema de facturación central con APIs existentes pero que requieren adaptación.

📄 Tronador (Oracle Legacy)

Core de pólizas On-Premise. Genera latencia y errores 500 intermitentes. Requiere circuit breakers y fallbacks para mantener estabilidad del portal.

Lectura Ejecutiva

El Portal de Intermediarios mantiene una estabilidad superior al 99.9% en producción. La arquitectura TO-BE migra de Legacy (Oracle + FileNet) a AWS (ECS + Lambda + RDS PostgreSQL) con MicroFrontends Angular.

Riesgo principal: Dependencia de Saghi para backends de Gestión Humana. Sin entrega en Junio 2026, el Entregable 6 no puede completarse en la ventana definida.

Dependencia crítica: Legacy Oracle (Tronador) y FileNet generan latencia y errores 500 que afectan la estabilidad de integraciones.

Fortaleza: Estabilidad operativa >99.9% + 31 ítems de excelencia operativa activos en 3 ecosistemas.
